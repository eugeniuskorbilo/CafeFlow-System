# CafeFlow - Система керування замовленнями в кафе

## Етапи виконання проєкту
1. Створено репозиторій.
2. Додано базову структуру проєкту.
3. Описано вимоги до навчального проєкту.
4. Створено окремі гілки для розробки.
5. Виконано коміти для кожного етапу.
6. Створено pull request і виконано злиття змін.
